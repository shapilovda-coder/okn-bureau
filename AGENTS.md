# ОКН.Проект: правила публикации

Этот репозиторий является источником production-сайта `https://oknproekt.ru`.
Страницы собираются как статические HTML-файлы в корне, а красивые URL
сопоставляются с ними в `server/server.js`.

## Обязательные правила

- Сохраняйте существующую визуальную систему: шрифты, цвета, header, footer,
  формы, мобильную панель связи, сетки и размеры кнопок.
- Для новых статей используйте последние опубликованные статьи как образец,
  прежде всего `blog-zony-ohrany-okn.html` и `blog-okn-krt.html`.
- Не придумывайте лицензии, специалистов, кейсы, цены, сроки, согласования и
  юридические последствия. Правовые утверждения проверяйте по официальным
  источникам.
- Не изменяйте `/api/lead`, аналитику, телефон, адрес или лицензионные данные
  без отдельного задания.
- Не добавляйте секреты, `.env`, токены, SSH-ключи и резервные копии.
- Не публикуйте напрямую на VPS. Работайте в отдельной ветке и создавайте PR.

## Новая статья

При добавлении статьи одновременно обновите:

1. новый `blog-*.html`;
2. карточку в `blog-static.html`;
3. маршрут в `server/server.js`;
4. URL и `lastmod` в `sitemap.xml`;
5. Vercel-маршруты командой `npm run vercel:routes`.

Страница должна иметь один H1, уникальные Title и Description, production
canonical, `index, follow`, BreadcrumbList, Article и синхронный с видимым
блоком FAQPage, если FAQ присутствует. Внутренние ссылки должны вести только
на существующие маршруты.

## Проверка

Перед PR выполните:

```bash
npm run check
npm run vercel:routes
npm run validate
npm run release:build
```

Vercel используется только для Preview. Production публикуется GitHub Actions
после проверки и слияния PR в `main`.
